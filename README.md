# MouseMobile

Управление ПК с телефона по Wi-Fi: тачпад, клавиатура и удалённый экран.
Тема AMOLED: чистый чёрный + тёмно-красный.

## 1. Сервер на ПК (Windows / macOS / Linux с X11)
1. Установите Python 3.9+ (python.org, отметьте «Add to PATH»).
2. Windows: запустите `pc-server/start_server.bat`.
   Остальные системы: `pip install -r requirements.txt` и `python mousemobile_server.py`.
3. В окне появятся IP и PIN. Брандмауэр спросит доступ — разрешите для частной сети.
   macOS: дайте Python права «Универсальный доступ» и «Запись экрана». Wayland не поддерживается.

## 2. Получить APK
**Вариант А — без установки программ (GitHub Actions):**
1. Бесплатный аккаунт на github.com → New repository → «uploading an existing file».
2. Перетащите ВСЁ содержимое папки MouseMobile, включая папку `.github` → Commit.
3. Вкладка Actions → «Build APK» → дождитесь зелёной галочки (≈5 мин) →
   внизу страницы в Artifacts скачайте `MouseMobile-apk` → внутри `MouseMobile.apk`.

**Вариант Б — Android Studio:** File → Open → папка MouseMobile → Build → Build APK(s).

Установка на телефон: разрешите установку из неизвестных источников.

## 3. Использование
Телефон и ПК в одной Wi-Fi сети. «Найти ПК в сети» (или IP вручную) + PIN → «Подключиться».
- Тачпад: 1 палец — курсор, тап — клик, 2 пальца — прокрутка, удержание или тап двумя пальцами — ПКМ. «Удерж.» — перетаскивание.
- Ввод: текст (любой язык) и клавиши, Alt+Tab, Win+D, громкость.
- Экран: картинка рабочего стола ПК; касание ставит курсор в эту точку, тап — клик.

## Безопасность
Трафик не шифруется. PIN новый при каждом запуске сервера, после 5 неверных попыток — блок на 5 минут.
Используйте только в домашней сети и не пробрасывайте порты 8765–8767 в интернет.
